O cadastro é gratuito para clientes e para profissionais. Basta informar nome, e-mail, senha e dados de contato, e escolher se você é cliente ou profissional. Profissionais também informam categoria, descrição e endereço, para aparecer nas buscas e no mapa. Se esquecer a senha, use a opção "esqueci minha senha" na tela de login: enviamos um e-mail com instruções para criar uma nova.
